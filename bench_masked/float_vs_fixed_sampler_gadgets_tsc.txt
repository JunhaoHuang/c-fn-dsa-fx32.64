Interpretation notes:
- masked_FALCON SamplerZ accepts sigma and computes its masked inverse inside.
  mrx160_sampler_z accepts isigma, matching the fixed-point FN-DSA sampler API.
  Therefore 63.63x (fixed inverse + SamplerZ) is the like-interface result;
  137.25x isolates sampling when isigma is already available.
- The fixed BerExp performs the legacy lazy byte comparison; the floating
  implementation accepts a pre-masked full 64-bit uniform word. Both used the
  same public word for this measurement, and the accept decisions matched.
- Representations, random generators, and circuits differ. These figures
  compare the measured implementations, not equally optimized abstract models.
- Both RNGs are demo-only. The floating reference uses rand()/rand64(); the
  fixed implementation uses its deterministic LFSR for masks and a separate
  deterministic byte source for signature sampling.
- masked_FALCON retains the previously documented UB/sanitizer limitations.
