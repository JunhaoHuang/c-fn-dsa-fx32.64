Notes:
  * Values are TSC reference ticks, not hardware core cycles.
  * The benchmark validates reconstructed 5+3=8 and 5*3=15 before timing.
  * Different representations perform different internal work. In particular,
    fixed addition is linear while floating addition aligns a secret exponent.
  * The fixed fast multiplier requires a proved signed-160-bit product range.
    The 192-bit path is the conservative result without that proof.
  * Random generation is included, but all three use demo/test randomness.
  * The current fixed ring multiplication includes the recent random-first
    first-order repair; the older saved report predates that final cost.
  * Historical note: at capture time the public API still used the
    compatibility bridge. The later v2 integrated signer is measured in
    integrated_signing_summary.md and mask_integrated_signing_tsc.txt.
